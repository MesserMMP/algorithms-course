# Stack vs Queue

Реализация: `solution.py`. Python 3.10+, только стандартная библиотека.

## Интерфейс и идея

`Stack`: `push(value)`, `pop()`, `peek()`, `is_empty()`, `len(stack)`.
`Queue`: `enqueue(value)`, `dequeue()`, `peek()`, `is_empty()`, `len(queue)`.
Добавление возвращает `None`, извлечение возвращает значение. `peek()` читает
значение без удаления. Извлечение и `peek()` на пустой структуре вызывают
`IndexError`. Можно хранить любые значения, включая `None` и повторы.
Итерация по стеку идёт от вершины, по очереди — от головы к хвосту;
не изменяйте структуру во время итерации.

Каждый `_Node` содержит значение и ссылку `next`. Python-список для хранения
элементов не используется. Стек добавляет новый узел перед `_head`, а при
извлечении передвигает `_head` на следующий узел. Это LIFO.
Очередь хранит `_head` и `_tail`: новый узел присоединяется к хвосту,
извлекается голова. Это FIFO. После удаления последнего узла оба указателя
равны `None`, поэтому повторное добавление корректно.

Инвариант стека: голова — последний ещё не извлечённый узел, цепочка хранит
остальные в обратном порядке добавления. Обе операции сохраняют инвариант.
Инвариант очереди: цепочка от головы до хвоста хранит оставшиеся узлы
в порядке добавления, `tail.next is None`. Добавление в конец и удаление
начала сохраняют порядок. Счётчик `_size` изменяется ровно на один при
успешном добавлении или удалении.

## Сложность

| Операция | Время | Дополнительная память |
| --- | --- | --- |
| push / enqueue | O(1) | O(1), один узел |
| pop / dequeue / peek | O(1) | O(1) |
| len / is_empty | O(1) | O(1) |
| Полный обход | O(n) | O(1) у итератора |

Хранение всей структуры — O(n), по одному узлу на элемент. `list(structure)`
дополнительно создаёт список размера n; сам итератор этого не делает.

## Пошаговая визуализация

Слева — вершина стека / голова очереди. Справа у очереди — хвост.
Все цепочки заканчиваются `None`.

| Шаг | Операция | Стек | Очередь | Извлечено: стек / очередь |
| --- | --- | --- | --- | --- |
| 0 | Начало | ∅ | ∅ | — |
| 1 | Добавить 4 | 4 | 4 | — |
| 2 | Добавить 8 | 8 → 4 | 4 → 8 | — |
| 3 | Добавить 15 | 15 → 8 → 4 | 4 → 8 → 15 | — |
| 4 | Извлечь | 8 → 4 | 8 → 15 | 15 / 4 |
| 5 | Добавить 16 | 16 → 8 → 4 | 8 → 15 → 16 | — |
| 6 | Извлечь | 8 → 4 | 15 → 16 | 16 / 8 |
| 7 | Извлечь | 4 | 16 | 8 / 15 |
| 8 | Извлечь | ∅ | ∅ | 4 / 16 |

Интерактивное сравнение: `../visualization/` (инструкция запуска в README ДЗ).

## Пример использования

Из корня репозитория:

```python
from homework_2.stack_vs_queue.solution import Stack, Queue

stack = Stack()
queue = Queue()
for value in [4, 8, 15]:
    stack.push(value)
    queue.enqueue(value)
assert stack.pop() == 15
assert queue.dequeue() == 4
```
