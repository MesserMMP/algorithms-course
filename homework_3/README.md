# Алгоритмы на Python · Домашняя работа 3

Три самостоятельных Python-решения, тесты и интерактивная лаборатория
хеширования. Вся работа находится в `homework_3/`, структура аналогична ДЗ2.
Python 3.10+, без сторонних Python-библиотек.

| Задача | Решение | Ожидаемая сложность |
|---|---|---|
| [Two sum](two_sum/README.md) | Словарь дополнений, один проход | O(n) время, O(n) память |
| [Anagrams](anagrams/README.md) | Группировка по отсортированным символам | O(nm log m) время, O(nm) память при m ≥ 2 |
| [Hash table](hash_table/README.md) | Цепочки на списках, расширение при нагрузке > 0.75 | O(1) амортизированно на вставку, O(n+c) память |
| [Визуализация](visualization/README.md) | React + TypeScript + Motion | Три пошаговые лаборатории |

В каждой папке задачи: `solution.py`, `test_solution.py`, `README.md`.
README содержат идею, доказательство корректности, оценки (включая худшие
случаи), статические схемы и описание тестов.

## Самый простой запуск: Docker

Из корня репозитория (нужен запущенный Docker Engine / Docker Desktop):

```bash
docker compose -f homework_3/visualization/docker-compose.yml up --build -d
```

Открыть **[http://localhost:8083](http://localhost:8083)**.
Приложение доступно также на `/visualization/`.
Если порт занят, добавьте `PORT=8093` перед командой.

Python-тесты без установки Python:

```bash
docker compose -f homework_3/visualization/docker-compose.yml --profile tests run --build --rm tests
```

Остановить:

```bash
docker compose -f homework_3/visualization/docker-compose.yml down
```

## Локальные проверки

```bash
python3 -m unittest discover -s homework_3 -t . -v
```

17 тестовых методов включают полный перебор малых входов, независимые
эталоны, детерминированные случайные сценарии, коллизии и 100 000 элементов.
Также можно запускать `python3 -m unittest -v` из папки каждой задачи.

Для интерфейса нужен Node.js 24+:

```bash
cd homework_3/visualization
npm ci
npm test
npm run build
npm run dev
```

Открыть [http://localhost:5175](http://localhost:5175).
Браузерные тесты и проверки адаптивности:

```bash
# Из homework_3/visualization
npx playwright install chromium
npm run test:e2e
```

## Что есть в лаборатории

- Три задачи и готовые сценарии, включая коллизии, повторы и Unicode.
- Собственные данные с валидацией, пошаговый режим, перемотка, пауза, скорость.
- Содержимое словаря, подписи анаграмм, цепочки и расширения хеш-таблицы.
- Объяснение текущего шага, краткая схема алгоритма и оценки сложности.
- Исходные Python-файлы и тесты загружаются непосредственно из папок задач;
  их можно скачать из интерфейса.
- Адаптивная компоновка, видимый клавиатурный фокус, reduced motion,
  локальные системные шрифты без CDN.

Проверки во вкладке «Тесты» запускают TypeScript-модель в браузере.
Они **не запускают Python**: для него используется unittest выше.
Интерфейс ограничивает размеры примеров ради читаемости, Python-решения
таких ограничений не имеют. «Все возможные случаи» для неограниченного
входа перебрать невозможно; тесты покрывают классы границ и используют
полный перебор в малой области плюс сравнение с эталоном.
