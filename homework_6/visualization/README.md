# Визуализация ДЗ6

В Compare, Iterative и K-th показаны действия Python-решений. Для слияния алгоритм записывает, из какой серии берёт каждое число. Для разбиения он записывает сравнение с опорой, обмен и новые границы групп. Повторяющиеся значения имеют собственные идентификаторы, поэтому при перемещении можно проследить каждое вхождение. Объяснение, оценки сложности и код выбранного метода раскрываются под демонстрацией.

В своём примере можно задать до 16 целых чисел от −999 до 999. Для Quickselect укажите k от 1 до длины массива. Эти ограничения действуют в интерфейсе.

## Разработка

Для локального запуска нужны Node.js 24 и Python 3.10 или новее. Из корня репозитория запустите сервер:

```sh
python3 -m homework_6.visualization.server
```

Во втором терминале:

```sh
cd homework_6/visualization
npm ci
npm run dev
```

Откройте [страницу разработки](http://localhost:5178/). Vite проксирует запросы Python-серверу. Команда `npm run build` проверяет типы и собирает приложение для запуска на порту 8086.

При запущенном сервисе на порту 8086 из этой папки можно проверить интерфейс в Chromium:

```sh
npx playwright install chromium
npm run test:e2e
```
