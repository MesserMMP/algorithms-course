# Iterative · сортировки без рекурсии

```python
from homework_6.iterative.sorts import mergesort, quicksort

data = [4, 7, 1, 4, 2, 6, 3]
assert mergesort(data) == quicksort(data) == [1, 2, 3, 4, 4, 6, 7]
```

Обе функции работают с копией входного массива. Наблюдать отдельные шаги можно в визуализации или передав функции `on_event=frames.append`, где `frames` — пустой список.

## Слияние снизу вверх

Серия — уже упорядоченный участок. В начале каждая серия состоит из одного элемента. На каждом проходе сливаем соседние серии вдвое большей длины. Последняя серия может быть короче, а если у неё нет пары, оставляем её на месте. После прохода все получившиеся серии упорядочены по свойству слияния. Когда длина серии достигает длины массива, весь массив упорядочен.

| Ширина серий перед проходом | Серии после прохода |
|---:|---|
| 1 | `[4, 7] │ [1, 4] │ [2, 6] │ [3]` |
| 2 | `[1, 4, 4, 7] │ [2, 3, 6]` |
| 4 | `[1, 2, 3, 4, 4, 6, 7]` |

На каждом из O(log n) проходов обрабатываем O(n) элементов. Время O(n log n), буфер занимает O(n) памяти. При равных значениях слияние берёт левый элемент первым, поэтому сортировка стабильна.

## Быстрая сортировка с явным стеком

Храним полуинтервалы `[lo, hi)`, которые предстоит упорядочить. Снимаем верхний участок, разбиваем относительно его первого элемента на три группы. Все равные опоре уже стоят на подходящих позициях. Кладём в стек обе оставшиеся группы длиной хотя бы два, начиная с большей. Пока в стеке есть участки, работа продолжается. После последнего разбиения на месте каждого участка остаётся упорядоченная последовательность.

| Участок и опора | Группы после разбиения этого участка | Стек после добавления новых участков, вершина справа |
|---|---|---|
| `[0, 7)`, опора 4 | `[3, 1, 2] │ [4, 4] │ [6, 7]` | `[0, 3), [5, 7)` |
| `[5, 7)`, опора 6 | `[] │ [6] │ [7]` | `[0, 3)` |
| `[0, 3)`, опора 3 | `[1, 2] │ [3] │ []` | `[0, 2)` |
| `[0, 2)`, опора 1 | `[] │ [1] │ [2]` | пуст |

В среднем на случайной перестановке различных элементов требуется O(n log n) времени. Убывающий массив из различных значений даёт O(n²), массив из равных значений — O(n). Поскольку меньшую часть обрабатываем первой, каждое накопление ещё одного отложенного участка означает переход к части размером не больше половины родительской. Стеку достаточно O(log n) памяти. Само разбиение работает на месте и может менять порядок равных элементов.

Для обеих функций список результата занимает ещё O(n). Отдельная история шагов создаётся только по запросу.
