# K-th · k-й по величине элемент

```python
from homework_6.kth.quickselect import kth_largest

assert kth_largest([3, 2, 1, 5, 6, 4], 2) == 5
assert kth_largest([3, 2, 3, 1, 2, 4, 5, 5, 6], 4) == 4
```

Ранг k отсчитывается от 1 по убыванию. Повторяющееся значение занимает столько мест, сколько раз встречается. Поэтому для `[9, 9, 1]` первый и второй элементы по величине равны 9. Допустимы целые k от 1 до n включительно.

## Алгоритм и корректность

Если бы массив упорядочили по возрастанию, ответ имел бы индекс `target = n - k`. Quickselect выбирает случайную опору и за один проход переставляет элементы текущего участка в три группы. Пусть равные значения теперь занимают полуинтервал `[lt, gt)`. Элементы левее него меньше опоры, правее — больше. Значит, опора занимает ровно те позиции по значению, которые ей принадлежат в упорядоченном массиве.

Если target лежит в средней группе, ответ найден. При `target < lt` продолжаем слева, при `target >= gt` — справа. Оставшийся участок всегда содержит ответ и строго короче предыдущего. При длине один ответом служит его единственный элемент. Для исходного массива создаётся рабочая копия, разбиение идёт внутри неё.

## Пример с повторами

Для `[3, 2, 3, 1, 2, 4, 5, 5, 6]` и k = 4 получаем target = 5. Последовательность опор ниже можно воспроизвести, передав `rng=random.Random(1)`.

| Шаг | Что произошло | Положение цели |
|---|---|---|
| 1 | Опора 3. Получили группы `[2, 1, 2] │ [3, 3] │ [5, 5, 6, 4]` | Равные занимают `[3, 5)`. Индекс 5 лежит правее |
| 2 | В участке `[5, 9)` выбрали опору 5. Получили `[4] │ [5, 5] │ [6]` | Равные занимают `[6, 8)`. Оставляем `[5, 6)` |
| 3 | В оставшемся участке один элемент | Ответ **4**. Первые три числа рабочей копии всё ещё расположены как `[2, 1, 2]` |

## Сложность

Пронумеруем элементы по возрастанию от 1 до m, в произвольном порядке внутри групп равных. Как минимум половина возможных опор имеет ранг от ⌈m/4⌉ до ⌈3m/4⌉ включительно. После такого выбора остаётся не больше 3m/4 элементов. В среднем хватает двух попыток, чтобы так сократить участок. Ожидаемая сумма затрат ограничена геометрической прогрессией с первым членом порядка n, что даёт O(n) времени. В худшем случае с каждого края исключается только один элемент и время достигает O(n²). Если все элементы равны, достаточно одного прохода.

Цикл разбиения использует O(1) дополнительной памяти. Рабочая копия для сохранения исходного массива занимает O(n), так что полная дополнительная память функции равна O(n). При включённой визуализации история отдельно хранит снимки массива.
