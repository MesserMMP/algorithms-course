# ДЗ5 · Рекурсия и AVL

Решения находятся в `tracer/`, `permutations/`, `AVL/`. Каждая папка содержит Python-код, тесты, объяснение, оценку сложности и пошаговый пример. Интерактивное приложение React + TypeScript находится отдельно в `visualization/`.

## Запуск

Из корня репозитория:

```sh
docker compose -f homework_5/visualization/docker-compose.yml up --build -d
```

Открыть http://localhost:8085/visualization/ . Сервер исполняет настоящие Python-решения и отдаёт историю событий. Браузер воспроизводит её с паузой, перемоткой и выбором скорости. Повороты показывают затронутое поддерево, завершённые операции — всё дерево.

```sh
python3 -m unittest discover -s homework_5 -t . -v
docker compose -f homework_5/visualization/docker-compose.yml --profile tests run --build --rm tests
docker compose -f homework_5/visualization/docker-compose.yml down
```

## Локальная разработка

Node.js 24+, Python 3.10+. В двух терминалах из корня:

```sh
python3 -m homework_5.visualization.server
```

```sh
cd homework_5/visualization
npm ci
npm run dev
```

Открыть http://localhost:5177 . Vite проксирует `/api` к Python на 8085. Проверка типов и сборка: `npm run build`. Браузерные проверки: `npm run test:e2e` (заранее установить Chromium: `npx playwright install chromium`; Python-сервер должен работать).

## Соглашения

- Tracer предназначен для обычных синхронных функций. Генераторы и async-функции не поддерживаются. Исключения пробрасываются, глубина восстанавливается.
- Permutations возвращает уникальные перестановки, включая `[[]]` для пустого массива. Декоратор используется для каждого рекурсивного вызова. `emit=print` включает текстовый журнал.
- AVL хранит множество целых ключей: повторная вставка и удаление отсутствующего ключа ничего не меняют; поиск возвращает bool. Высота пустого дерева 0, листа 1.
- Ограничения интерфейса защищают браузер от огромной истории: n ≤ 8, до 5 элементов для перестановок, до 25 операций AVL и ключи −999…999. Python-алгоритмы этих ограничений не имеют.
- Оценки сложности относятся к алгоритмам без визуализации. Снимки деревьев и полная история занимают дополнительное время и память пропорционально объёму записанных данных. Tracer тратит время на форматирование аргументов и результатов.
