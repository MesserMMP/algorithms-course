# Интерактивная визуализация ДЗ5

React + TypeScript, события из настоящих Python-алгоритмов через локальный API. Инструкции запуска и ограничения: [README ДЗ5](../README.md).

- **Tracer:** дерево вызовов, текущая формула с результатами дочерних вызовов, живой стек и журнал с отступами. Неизвестные результаты скрыты до возврата.
- **Permutations:** позиции перестановки, оставшиеся элементы, развилки дерева решений, стек и накопленные результаты. Завершённые вызовы доступны для повторного разбора нажатием на узел.
- **AVL:** перемещение узлов при поворотах, высоты и баланс, шкала допустимого баланса, упорядоченные ключи и переключение «до / после» поворота. Во время поворота показано локальное поддерево, после операции — всё дерево.

Янтарный цвет обозначает текущий вызов, синий — возврат результата, зелёный — завершённую ветку. Возврат показан до снятия кадра со стека. Связи проявляются по направлению вызова или возврата; схема занимает всю ширину и по умолчанию вписывается целиком. Кнопки масштаба позволяют увеличить детали; «Вписать всё» возвращает полный обзор. Стек, журнал и результаты раскрыты без внутренних ограничений высоты. При reduced motion движения отключены.

Режим «Развернуть» освобождает экран для схемы и результатов; Esc возвращает обычный вид. Есть готовые примеры, собственный ввод, пошаговое управление, скорость 0.5×/1×/2×, исходники и тесты. `npm run test:e2e` проверяет каждый шаг готовых примеров на ширинах 320, 390, 768, 1024 и 1440 px, результаты возврата, длинные значения, 120 перестановок, управление и сравнение поворотов. Для браузерных проверок нужен запущенный сервис на порту 8085.
