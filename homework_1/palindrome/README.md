# Задача 1. Палиндром

## Решение
`solution.py`, функция `is_palindrome(number)`.
Отделяем последнюю цифру остатком от деления на 10, добавляем её к развёрнутой половине, а исходную часть делим на 10 нацело. Останавливаемся, когда оставшаяся часть не больше развёрнутой. Для чётного количества цифр сравниваем половины напрямую; для нечётного отбрасываем центральную цифру развёрнутой части. Строки в решении не используются. Число с конечным нулём (кроме 0) и отрицательное число не могут быть палиндромами. Дополнительно определяем 0 как палиндром; нецелые значения, включая bool, вызывают TypeError.

## Почему работает
После каждого шага reversed_half содержит последние обработанные цифры исходного числа в обратном порядке, remaining_number — необработанный префикс. У палиндрома эти половины совпадают после удаления центральной цифры, если она есть. Для непалиндрома ни одно из двух сравнений не выполнится.

## Сложность
Пусть d — количество десятичных цифр. В стандартной модели арифметических операций: O(d) = O(log number) времени, O(1) дополнительных числовых переменных. В Python целые числа произвольной длины: хранимые значения занимают O(d) бит, а суммарная стоимость арифметики для очень больших чисел — O(d²) битовых операций. Для 0 время константное.

## Визуализация: 1234321
| Шаг | Последняя цифра | remaining_number | reversed_half |
| --- | --- | --- | --- |
| 0 | — | 1234321 | 0 |
| 1 | 1 | 123432 | 1 |
| 2 | 2 | 12343 | 12 |
| 3 | 3 | 1234 | 123 |
| 4 | 4 | 123 | 1234 |

123 <= 1234, цикл завершён. 123 == 1234 // 10, результат True. Для 1221 половины равны напрямую. Для 12345 оба сравнения ложны. Интерактивный разбор с собственным вводом находится в веб-приложении.

## Тесты и запуск
Из этой папки: `python -m unittest -v`.
Тесты включают примеры, 0, одноразрядные числа, чётную/нечётную длину, нули внутри и в конце, отрицательные числа, большие целые и неверные типы. Все числа от 0 до 9999 сравниваются с независимым строковым эталоном (строки разрешены только в тестах).
Запуск решения: `python solution.py`, затем введите число.
