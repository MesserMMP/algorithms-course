# Задача 2. Максимальная чётная сумма

## Решение и обоснование
`solution.py`, функция `maximum_even_sum(numbers)`.
За один проход находим общую сумму и минимальный нечётный элемент. Все элементы положительные, поэтому максимальная возможная сумма — сумма всего массива. Если она чётная, возвращаем её. Иначе надо исключить нечётную сумму. Любая такая исключённая группа содержит хотя бы одно нечётное число и весит не меньше минимального нечётного элемента. Поэтому оптимально удалить только этот минимальный элемент.
Пустой массив даёт 0, один нечётный элемент — также 0: разрешена пустая выборка. Нулевые и отрицательные элементы вызывают ValueError, нецелые (включая bool) — TypeError. Функция не меняет вход и работает с итераторами.

## Сложность
O(m) времени для m элементов, O(1) дополнительных числовых переменных: один проход, без сортировки и без копии массива. Оценка дана в модели операций над целыми за O(1). Для произвольно больших Python int стоимость арифметики зависит от разрядности; аккумулятор занимает O(log(total_sum + 1)) бит.

## Визуализация: [5, 7, 13, 2, 14]
| Шаг | Элемент | Сумма | Минимальное нечётное |
| --- | --- | --- | --- |
| 0 | — | 0 | — |
| 1 | 5 | 5 | 5 |
| 2 | 7 | 12 | 5 |
| 3 | 13 | 25 | 5 |
| 4 | 2 | 27 | 5 |
| 5 | 14 | 41 | 5 |

41 нечётно. Исключаем 5: 41 − 5 = 36. Остаются 7, 13, 2, 14. Дополнительные случаи: [4, 8, 6, 12] → 30 без исключения; [3] → 0. Интерактивный разбор доступен в веб-приложении.

## Тесты и запуск
Из этой папки: `python -m unittest -v`.
Проверяются примеры, пустой массив, один элемент, все чётные/нечётные, повторы, большие числа, отсутствие изменения массива, одноразовый итератор, большой поток и ошибочные значения. Все массивы длины 0–5 из чисел 1–4 и 100 воспроизводимых случайных массивов сравниваются с полным перебором подмножеств.
Запуск решения: `python solution.py`, затем введите числа через пробел.
